# cabal-gild

`cabal-gild` formats Haskell package descriptions and cabal project files. It normalizes layout, sorts and deduplicates `build-depends`, and can refresh module lists generated by `-- cabal-gild: discover`.

## Format In Place

Run on each touched cabal/project file:

```sh
cabal-gild --io <file>
```

Format before compiling.

## Check Without Writing

```sh
cabal-gild -m check --io <file>
```

## Auto-Discovered Module Lists

If a `.cabal` file contains a pragma like this:

```cabal
-- cabal-gild: discover src
exposed-modules:
```

rerun `cabal-gild --io <pkg>.cabal` after adding or removing modules.

## Project Automation

This repository already has a pre-commit hook that runs `cabal-gild` over cabal/project files.

This repository also has a Codex `PostToolUse` hook in `.codex/hooks.json` that runs `.codex/hooks/cabal-gild-post-tool-use.sh` after `apply_patch` edits. Re-read files if the hook reports that it changed them.
